# Arquivo

O que saiu da memória ativa. Nada aqui é apagado, e nada aqui entra no contexto do agente.

Cada arquivo guarda o caminho que tinha, com `archived_at` e `reason` no frontmatter.
`housekeeping/` tem o registro de cada housekeeping: o que foi aplicado, o que a pessoa
recusou e quem aprovou.

Para trazer algo de volta, mova o arquivo para o lugar antigo e tire os dois campos.
